# 02 — التثبيت خطوة بخطوة

> هذه الخطوات مبنية على الدليل الرسمي لمشروع TheMojoMan، ومُتحقَّق منها على جهاز حقيقي.
> **الزمن المتوقع:** 30–60 دقيقة + وقت التنزيل.
>
> الأوامر نفسها تعمل على **لينكس** و**ويندوز** (PowerShell). لتجهيز الحاسوب ومعرفة
> الفروق والمشاكل الخاصة بكل نظام: [12-platforms.md](12-platforms.md).

## 0. قبل البدء — قائمة تحقّق

- [ ] البوتلودر مفتوح (`fastboot getvar unlocked` → `yes`)
- [ ] نسخة احتياطية من `boot_b` وبياناتك ([01-prerequisites.md](01-prerequisites.md#4-النسخ-الاحتياطي-لا-تتجاوز-هذه-الخطوة))
- [ ] الصورة **مفكوكة الضغط** `ubuntu-26.04-xiaomi-nabu.img`
- [ ] `V4-MODDED-TWRP-LINUX.img` و `efi.tar` و `setup_ubuntu.sh` و `installer_bootmanager_NOSB.zip` جاهزة
- [ ] بطارية التابلت **أكثر من 50%**

---

## 1. الدخول إلى وضع Fastboot

1. أطفئ التابلت تماماً.
2. **اضغط مطولاً زر خفض الصوت (Volume Down)** ثم وصّل كابل USB بالحاسوب.
3. سيُقلع على شاشة سوداء/بيضاء مكتوب عليها `FASTBOOT`. اترك الزر.

```bash
fastboot devices
# مثال: 3f8a1b2c	fastboot
```

> إن لم يظهر شيء: جرّب كابلاً آخر، أو منفذ USB مباشراً في اللوحة (لا Hub).

---

## 2. إقلاع TWRP المعدّل

```bash
fastboot boot V4-MODDED-TWRP-LINUX.img
```

- العملية **لا تُثبّت** TWRP، بل تُقلعه مؤقتاً من الذاكرة.
- إن فشلت المحاولة (شاشة سوداء أو رجوع سريع لـ Fastboot)، **أعد المحاولة 2–3 مرات** — هذا سلوك معروف.
- عند نجاحها تظهر واجهة TWRP اللمسية.

> TWRP المعدّل ضروري لأنه يفكّ تشفير/يقرأ أقسام أندرويد الحديثة ويسمح بكتابة ESP.

---

## 3. نسخ ملفات التثبيت إلى الذاكرة المؤقتة

في نافذة طرفية على الحاسوب:

```bash
adb devices                          # يجب أن يظهر الجهاز كـ "recovery"
adb push setup_ubuntu.sh /tmp/
adb push efi.tar /tmp/
adb shell "chmod +x /tmp/setup_ubuntu.sh"
```

---

## 4. تشغيل سكربت التقسيم

```bash
adb shell "/tmp/setup_ubuntu.sh"
```

### خيارات السكربت (بالترتيب)

| الخيار | ما تختاره | لماذا |
|---|---|---|
| **Dry-Run** | **Yes أولاً** | محاكاة آمنة تعرض ما سيحدث دون تنفيذ. |
| **Mode** | `1` = مسح أندرويد كلياً / `2` = **إعادة تقسيم مع إبقاء أندرويد** | للإقلاع المزدوج اختر `2`. |
| **Layout** | `2` = **esp + linux + data** | يسمح بإعادة تثبيت لينكس دون فقدان بياناتك. |

> `userdata` سيُعاد تقسيمه — **بيانات أندرويد ستُفقد على الأرجح** حتى مع الإقلاع المزدوج.

### ما يفعله السكربت

1. يُقلّص/يُعيد تقسيم `userdata`.
2. يُنشئ قسم `linux` (ext4) وقسم `data` (ext4) و`esp` (FAT32).
3. ينسخ محتويات `efi.tar` إلى ESP (rEFInd + ملفات النواة).
4. يهيّئ ESP.

### الشكل الناتج

```
esp   → FAT32  (~500MB)   /dev/sda31 عندنا
linux → ext4   (30–60GB)  /
data  → ext4   (الباقي)   /media/data
```

سجّل أسماء الأقسام — ستحتاجها لاحقاً:

```bash
adb shell "ls -l /dev/block/by-name/ | grep -E 'esp|linux|data'"
```

---

## 5. كتابة نظام أوبونتو

أعد التابلت إلى **Fastboot** (من قائمة TWRP: Reboot ← Fastboot)، ثم:

```bash
# تأكّد أن القسم موجود باسم linux
fastboot getvar all 2>&1 | grep -i linux

# اكتب الصورة (قد تستغرق 5–15 دقيقة)
fastboot flash linux ubuntu-26.04-xiaomi-nabu.img
```

> ⚠️ لا تكتب الصورة على `boot_a`/`boot_b` — هذه خاصة بأندرويد.

---

## 6. تصحيح البوتلودر (DBPK Bootmanager)

هذه الخطوة تجعل البوتلودر يعرف أن القرص يحتوي لينكس (وأن أندرويد ما زال موجوداً).

1. من Fastboot: `fastboot boot V4-MODDED-TWRP-LINUX.img` (مرة أخرى).
2. في TWRP: **Advanced → ADB Sideload** ثم اسحب شريط التأكيد.
3. على الحاسوب:

```bash
adb sideload installer_bootmanager_NOSB.zip
```

4. انتظر `Total xfer: 1.00x` ثم أعد التشغيل من TWRP: **Reboot → System**.

### ما الذي يفعله هذا الملف؟

يفكّ حزمة تحتوي:

| الملف | الوظيفة |
|---|---|
| `DualBootKernelPatcher` | يُرقّع نواة أندرويد لتفهم خريطة الذاكرة المشتركة |
| `ShellCode.NabuPStore.bin` | تعليمات تُنفَّذ عند إقلاع أندرويد |
| `DualBoot.Sm8150.cfg` | حدود المكدّس (`StackBase=0x9FC00000`, `StackSize=0x300000`) |
| `SM8150_EFI.fd` | نسخة UEFI المعدَّلة للإقلاع من القرص |
| `magiskboot` | أدوات فك/تركيب صور الإقلاع |

> بعد هذه الخطوة يظهر **rEFInd** عند كل إقلاع بدل شاشة شاومي.

## 7. أول إقلاع

1. يظهر rEFInd لمدة 5 ثوانٍ ثم يُقلع النواة الافتراضية.
2. **إن بقيت الشاشة سوداء أكثر من 30 ثانية:**
   - اضغط زر الطاقة مطولاً حتى يُعيد التشغيل، واختر النواة الأخرى من القائمة.
   - السبب المعروف: **النواة 6.17 لا تُقلع على كل الأجهزة** (خصوصاً أقراص Samsung UFS)،
     بينما **6.14.11 تُقلع على كل الأجهزة**.
3. عند نجاح الإقلاع يظهر معالج الإعداد الأولي لأوبونتو:
   - اللغة (يمكن اختيار English للواجهة)، المنطقة الزمنية، اسم المستخدم وكلمة المرور.
   - الشبكة: اختر واي فاي المنزل.
4. بعد الدخول افتح Terminal وتحقق:

```bash
uname -r                      # 6.17.0-xiaomi-nabu-tmm-UFS-slowdown+ أو 6.14.11-nabu-tmm+
lsblk -o NAME,SIZE,PARTLABEL,MOUNTPOINT | grep -E 'esp|linux|data'
```

## 8. التحقق النهائي من التثبيت

```bash
# 1) النواة وسطر الأوامر
uname -r; cat /proc/cmdline

# 2) منفذ USB-C (يجب أن يظهر port0)
ls /sys/class/typec/

# 3) أجهزة الإدخال (لمس/قلم/لوحة مفاتيح)
grep -H . /sys/class/input/input*/name

# 4) الواي فاي
nmcli device status

# 5) الشحن — وصّل الشاحن ثم:
cat /sys/class/power_supply/*/status
```

أو ببساطة:

```bash
sudo bash scripts/diagnostics/health-check.sh
```

## 9. إن فشل شيء

| المشكلة | الحل |
|---|---|
| `fastboot boot` يفشل دائماً | جرّب كابلاً/منفذاً آخر، وأعد المحاولة 3 مرات |
| الجهاز يقف على شعار شاومي | أعد الإقلاع إلى TWRP وكرّر الخطوة 6 (sideload) |
| شاشة سوداء بعد rEFInd | اختر `6.14.11` من القائمة |
| rEFInd لا يظهر | لم تُنفَّذ الخطوة 6 بالكامل — كرّرها |
| لا يوجد قسم `linux` | لم يكتمل التقسيم — أعد تشغيل `setup_ubuntu.sh` |
| الشحن لا يعمل | [06-charging.md](06-charging.md) |
